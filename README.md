# Offline Mailing System

A desktop-style offline mailing application developed during internship.

---

## Features

- User Registration
- Login Authentication
- Forgot Password
- Change Password
- Dashboard
- Compose Mail
- Inbox
- Calendar
- Profile
- File Attachments

---

## Tech Stack

### Frontend

- React
- Vite
- CSS
- Axios

### Backend

- Java
- Spring Boot
- Spring Data JPA

### Database

- MySQL

---

Offline-Mailing-System

---

## Backend Setup

1. Install MySQL

2. Create database

```
login_system
```

3. Open

```
application.properties
```

4. Update

```
spring.datasource.username=YOUR_USERNAME
spring.datasource.password=YOUR_PASSWORD
```

5. Run

```
mvn spring-boot:run
```

---

## Frontend Setup

```
cd "basic intership"

npm install

npm run dev
```
